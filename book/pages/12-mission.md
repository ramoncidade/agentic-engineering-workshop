# Mission

Contexto explica o mundo.

Mission transforma esse mundo em trabalho.

Uma boa Mission combina:

**Contexto + Objetivo + Restrições + Critérios de aceite**

Exemplo:

> Implemente o cadastro preservando a compatibilidade com os clientes atuais. O CPF deve ser único. Crie testes de integração e entregue o pipeline verde.

Não existe uma coreografia de cada clique.

Existe um resultado verificável.
