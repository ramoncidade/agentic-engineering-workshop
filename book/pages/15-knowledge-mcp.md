# Knowledge e MCP

Em algum momento surge uma pergunta:

> "O agente precisa saber tudo isso toda vez?"

Não.

Conhecimento reutilizável pode ser organizado e disponibilizado.

**Knowledge**  
O que o agente precisa saber.

**MCP**  
Uma interface para o agente acessar ferramentas, recursos e sistemas externos.

Uma base de conhecimento pode conter uma Skill.

Um MCP pode permitir que o agente consulte essa base.

São papéis diferentes.

A AI Toolbox pode aparecer como exemplo de infraestrutura para organizar e distribuir conhecimento. O conceito continua válido sem ela.
