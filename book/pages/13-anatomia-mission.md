# A anatomia de uma Mission

```
CONTEXT
  ↓
OBJECTIVE
  ↓
CONSTRAINTS
  ↓
ACCEPTANCE
```

**Context**  
O que o agente precisa saber.

**Objective**  
O que precisa ser produzido.

**Constraints**  
O que não pode ser quebrado.

**Acceptance**  
Como saberemos que terminou.

A Mission é uma unidade de delegação que permite produzir um resultado verificável.
