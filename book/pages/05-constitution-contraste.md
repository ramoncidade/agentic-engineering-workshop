# Princípio ou receita?

### RUIM

```
Use Spring Boot.
Crie Controller.
Crie Service.
Rode o build.
```

Isso descreve passos.

### BOM

```
Preferimos soluções simples e observáveis.
Complexidade precisa comprar uma capacidade clara.
```

Isso orienta uma decisão.

Uma receita acompanha uma execução específica. Um princípio continua útil quando a situação muda.
