# Knowledge ≠ MCP

```
           AGENTE
              │
           HARNESS
              │
      ┌───────┴───────┐
      │               │
  KNOWLEDGE          MCP
      │               │
 o que saber     como acessar
      │               │
 Skills         GitHub / Figma
 padrões        APIs / Toolbox
 documentação   sistemas internos
```

Knowledge organiza conteúdo reutilizável.

MCP cria uma interface de acesso a capacidades externas.
