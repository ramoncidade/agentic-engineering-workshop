# Assets do livro

Os personagens existentes permanecem a fonte visual.

Referência:
`presentation/assets/characters/`

Quando faltar uma expressão ou pose, usar placeholder explícito no storyboard ou na página:

```
<img src="pietro-questionando.png" alt="Placeholder: Pietro questionando">
```

Convenção:
`{personagem}-{expressão}.png`

Exemplos:
- `claudinho-pensando.png`
- `pietro-pensando.png`
- `pietro-explicando.png`
- `bruno-investigando.png`

A ausência de um asset não deve interromper a construção editorial.
