# Agentic Engineering Workshop · Livreto Digital

Este diretório contém a versão editorial do livreto digital do Agentic Engineering Workshop.

O livro não é uma conversão da apresentação. A apresentação é fonte de conteúdo e storyboard; o livro é uma experiência de leitura própria.

## Tese

> O objetivo não é escrever mais prompts. É criar um sistema onde bons objetivos gerem bons resultados através de agentes.

A jornada do leitor é:

**Implementador → Delegador → Orquestrador**

## Estrutura

- `book/manifest.yml` — mapa editorial e ordem das páginas.
- `book/storyboard.md` — storyboard detalhado.
- `book/pages/` — texto editorial de cada página.
- `book/assets/README.md` — convenção de imagens e placeholders.
- `book/design.md` — direção visual.
- `book/review-checklist.md` — critérios de revisão.

## Regra editorial

A unidade do livro é a experiência do leitor, não o slide.

Cada página deve responder:

> O que eu deveria ter entendido depois de ler isso?

Cada seção deve ajudar na transição de executor para orquestrador.
