# Solid visual variant

This version intentionally moves away from the neon visual language toward a warmer, editorial presentation system: off-white canvas, charcoal text, muted blue-gray, restrained terracotta accent and solid cards.

It also replaces the placeholder circular avatars with illustrated character artwork for Cora Cronograma, Pedro Produteiro and Manuela Faz-Telas.

Open `index-solid.html` for the revised presentation.

Controls: arrows, Space, Home/End, F for fullscreen, horizontal swipe on touch devices.
