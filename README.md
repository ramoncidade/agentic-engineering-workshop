# Agentic Engineering Workshop

Workshop sobre a evolução de engenharia de software orientada a chat para engenharia orientada a objetivos e agentes.

## Ideia central

O objetivo não é escrever mais prompts.

É aprender a organizar problemas, contexto, responsabilidades, ferramentas e validação para que agentes executem trabalho enquanto o humano atua como arquiteto, revisor, priorizador e integrador.

## Formato

O material será construído primeiro como um livro interativo em HTML/Markdown. A apresentação poderá ser derivada desse conteúdo posteriormente.

## Estrutura inicial

- `content/` capítulos do workshop
- `exercises/` exercícios práticos
- `facilitator/` guia do facilitador e checklists
- `constitution.md` princípios que orientam a construção do material
- `instructions.md` regras de produção e revisão
- `index.html` interface futura do livro/workshop

## Revisão anti-AI

Todo conteúdo passará por uma revisão específica para remover sinais artificiais de escrita, como repetição de ideias, excesso de slogans, estrutura excessivamente simétrica, explicações redundantes e prosa genérica ou polida demais.
