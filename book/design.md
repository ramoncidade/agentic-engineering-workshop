# Direção visual

## Linguagem

Contemporânea, técnica e editorial. Referência de gibi técnico: narrativa em quadros, balões de fala, cards, diagramas e blocos de código, sem estética infantil.

## Paleta

- azul profundo para estrutura;
- azul médio para destaque;
- azul claro para áreas de apoio;
- branco/off-white para páginas;
- cinzas neutros para texto e linhas;
- verde e vermelho apenas para estados de validação.

## Composição

Alternar:
- páginas de cena;
- páginas de conceito;
- páginas de contraste;
- diagramas;
- páginas de reflexão.

Evitar páginas compostas apenas por listas.

## Tipografia

Priorizar uma sans-serif limpa para narrativa e uma monoespaçada para código, labels e diagramas.

## Ritmo

O leitor deve alternar entre:
**ver → ler → entender → reconhecer no exemplo → avançar.**

Não transformar cada página em uma mini-aula.

## Assets

Reutilizar a identidade visual existente em `presentation/assets/characters`. Não criar versões novas de personagens sem necessidade.
