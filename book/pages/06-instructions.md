# Instructions

Constitution diz o que valorizamos.

Instructions transformam isso em regras aplicáveis ao trabalho cotidiano.

Por exemplo:

> "Toda chamada a API externa deve possuir timeout explícito, tratamento de erro e métricas de latência."

Agora existe comportamento esperado.

O agente não precisa redescobrir a regra toda vez.
