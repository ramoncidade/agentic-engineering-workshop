# Skills

Conhecimento pode ser transformado em procedimento.

Essa é a ideia de uma Skill.

Uma Skill deve permitir que um agente execute uma classe de tarefas sem redescobrir o processo inteiro.

### Exemplo: integração HTTP

1. analisar o contrato;
2. definir o cliente;
3. configurar timeout;
4. configurar retry quando aplicável;
5. configurar rate limit;
6. tratar erros;
7. adicionar observabilidade;
8. criar testes;
9. validar integração.

A Skill não é a tarefa.

É o procedimento reutilizável.
